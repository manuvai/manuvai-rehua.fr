## Formulaire VCRT
Parmi les différents formulaires que j'ai été amené à développer, j'ai développé un formulaire d'inscription à une course de vaa (course de canoe). Dans ce projet, il fallait gérer les entrées des utilisateurs dans le formulaire en effectuant des validations.

J'ai également implémenté un retour utilisateur via l'envoi d'un SMS pour confirmation.

## Jeu du morpion
### Contexte :
Lors de mon stage volontaire, on m'a donné la mission  de faire fonctionner le jeu qu'un ancien stagiaire avait élaboré. Je devais permettre au jeu du morpion de se dérouler en multijoueur.
Le jeu du morpion devait également être adapté à la plateforme de jeux pour permettre aux utilisateurs de celle-ci de voir le classement des 3 premiers joueurs.

### Technologies utilisées :
- PHP
- HTML / CSS
- Javascript

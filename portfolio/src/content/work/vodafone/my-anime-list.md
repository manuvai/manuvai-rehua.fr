## Formulaire VCRT
Ce projet a été élaboré durant mon cycle Licence, l'idée était de faire une copie à but éducatif du site myanimelist.fr en partant de zéro.

Nous devions :
- Utiliser notre propre palette de style
- Garder une structure cohérente à travers toutes les pages
- Permettre de faire la liaison avec la base de données en MySQL
- Utiliser un environnement PHP
- Faire des appels en Ajax pour modifier les données
